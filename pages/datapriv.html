Data & Privacy

CarePulse uses browser storage only. No records are uploaded or shared across devices.

On-Device Storage

Profiles, symptom entries and medication records remain in this browser’s local storage. There is no account, cloud synchronization, remote caregiver connection or backend connection in this demo.

  • ✓ Works offline after loading
  • ✓ No authentication tokens stored
  • ✓ No cross-device access
  • ✓ Records stay in this browser

Local Data Controls

Download a backup of your CarePulse data, or clear all CarePulse information from this browser.

Educational use

Use fictional or demonstration data

Browser local storage is not secure medical record storage. This college project is designed to demonstrate front-end care tracking functionality only.
